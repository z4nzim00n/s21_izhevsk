Частые вопросы

FAQ
Как учиться из дома?

Для работы из дома нужны Git и SSH-ключ, добавленный в GitLab.

  1. Установи Git: git-scm.com/downloads.
  2. Сгенерируй SSH-ключ на своей машине (ssh-keygen -t ed25519) и добавь публичный ключ в свой GitLab.
  3. Важно: если идёшь в разработческую ветку и работаешь в WSL — сгенерируй второй ключ прямо внутри WSL и тоже добавь его в GitLab.
  4. После этого работают базовые команды: git clone, git add, git commit, git push.
Что делать, если получилась офлайн-проверка вместо онлайн?

Проверку можно провести онлайн любым доступным способом. По опыту участников, записи проверок запрашивают только при конфликтах. Ответственность за проведение проверки и качество обучения остаётся за участниками.

Как получать PRP-поинты?

Подписка на доступные проекты позволяет проверять их без выполнения самих проектов. Чем меньше PRP на балансе, тем выше приоритет получения слота для проверки. Для получения слотов имеет смысл поддерживать нулевой баланс.

Как учитывается PRP при проверке и absence?
  1. При записи на проверку PRP списываются сразу.
  2. При отмене менее чем за 24 часа до проверки PRP не возвращаются. При более ранней отмене — возвращаются.
  3. Если один из участников не пришёл, необходимо подождать 15 минут от времени начала. После этого появляется кнопка absence. Если участник не отвечает, ждать дольше не требуется.
  4. Об отсутствии участника можно сообщить на почту ADM, приложив скриншоты переписки и попыток связаться. За отсутствие участнику могут назначить штраф.
  5. Если absence нажимает проверяемый, PRP возвращаются.
  6. Если absence нажимает проверяющий, проект проверяемого получает fail. Продолжение сдачи не изменит итоговую оценку: она составит 0%.
  7. После absence можно сразу записаться на новую проверку.
  8. Возврат PRP можно проверить в истории PRP в профиле.
  9. Во время акций и распродаж PRP учитывается момент завершения проверки, а не записи на неё. Проверку можно провести заранее и по договорённости завершить во время распродажи — тогда бонусы получат оба участника.

Важно: absence со стороны проверяющего приводит к провалу проекта сдающего. Перед нажатием необходимо убедиться, что участник действительно отсутствует. Если absence нажимает сдающий, штрафов для участников нет.

Как правильно пересдавать буткемп/интенсив?
  1. При повторном запуске буткемпа списывается начисленный за него XP.
  2. Для выполненных проектов нужно выбрать retry, затем give up. Им будет выставлена максимальная оценка за предыдущие попытки.
  3. Невыполненные проекты необходимо сдать заново.
  4. После повторного завершения буткемпа начисляется новый XP по средней оценке.
